# Frontend Foundation Challenge

Hey guys, Ankit here!

Now, you must be wondering, what is this?

Well, the thing is, I created this because nowadays I rely on AI too much, and I’ve noticed that my fundamentals have started to lag. It’s not like I’ve forgotten everything. I can still build things, but my brain has started treating AI like a shortcut — almost like sugar — and I’m worried that I’ll struggle in critical situations without it.

For instance, while I was working on a project, I had to implement something relatively simple. The solution was straightforward, but I ended up wasting **2.5 hours** on it.

The problem wasn't that I didn't know how to do it.

The problem was that, because I’ve become so used to relying on AI, I lost the rational approach I used to have. I used to be much better at breaking down a problem, thinking through it, and finding the solution myself.

I felt guilty about that and started thinking:

> **What if, for some reason, there is no AI in the future?**

Would the skills and career that I invested so much into still stand on their own, or have I become so dependent on AI that I can't confidently handle basic problems myself?

That question hit me really hard.

So I decided to start doing things on my own again — even if they seem simple.

- Designing things
- Building things
- Understanding how things work
- Solving problems without immediately reaching for AI

I want to train my brain again, bring that confidence back, and build such a strong foundation that it leads me toward becoming the developer I always wanted to be.

Of course, I'm not doing this just to remember basic syntax.

I'm doing this to rebuild my **foundational knowledge** and develop a deeper understanding of what I'm doing — so that I can confidently say:

> **Even if AI isn't available in the future, I still have myself.**

The skills I want to work on are:

- Problem-solving
- Pattern recognition
- Critical thinking
- Focus
- Directional planning
- Breaking problems down
- Building things independently

This particular challenge is focused on **frontend development**.

My goal is to complete **at least one challenge every day**.

And this challenge is never-ending.

If you think you can take on this challenge, go for it.

But remember:

> **Take action rather than just thinking about it.**

Good luck!
